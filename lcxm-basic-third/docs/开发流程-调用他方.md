# 开发流程：我方调用第三方

## 目标

每个第三方一个业务 Client，公共模块处理 HTTP 执行、响应解析和日志扩展点。

```text
业务服务
  -> 某第三方 Client
  -> OutboundRequestInfo
  -> HttpOutboundExecutor
  -> 第三方接口
```

## 开发步骤

1. 写项目配置类。

继承 `AbstractThirdOutboundConfiguration`，并在项目配置类上添加 `@Configuration`。

```java
@Configuration
public class ThirdOutboundConfiguration extends AbstractThirdOutboundConfiguration {

    @Override
    protected void saveThirdExchangeLog(ThirdExchangeLog log) {
        // 项目侧落库、MQ 或审计
    }
}
```

基类默认提供：

- `ThirdOptionsProvider`
- `ThirdExchangeLogger`
- `thirdOutboundExecutor(...)` 执行器创建方法

2. 定义第三方标识和配置来源。

业务项目维护 `thirdCode`、baseUrl、超时、默认 header、密钥、厂商参数等。

公共模块只提供：

- `ThirdIdentity`
- `ThirdClientOptions`
- `ThirdOptionsProvider`

如需按厂商区分超时、默认 header 或日志开关，覆盖 `thirdClientOptions(String thirdCode)`。

3. 编写第三方 Client。

继承 `AbstractOutboundClient`：

```java
public class KingdeeOutboundClient extends AbstractOutboundClient {

    public KingdeeOutboundClient(ThirdOptionsProvider optionsProvider, OutboundExecutor outboundExecutor) {
        super(optionsProvider, outboundExecutor);
    }

    @Override
    protected ThirdIdentity thirdIdentity() {
        return new ThirdIdentity("kingdee", "金蝶");
    }

    @Override
    protected String buildUrl(String path) {
        return "https://example.com" + path;
    }

    @Override
    protected Map<String, String> buildHeaders() {
        return Map.of("Content-Type", "application/json");
    }
}
```

4. 在配置类中声明第三方 Client。

```java
@Bean
public KingdeeOutboundClient kingdeeOutboundClient(ThirdOptionsProvider optionsProvider,
        ThirdExchangeLogger exchangeLogger) {
    OutboundExecutor executor = thirdOutboundExecutor("kingdee", optionsProvider, exchangeLogger);
    return new KingdeeOutboundClient(optionsProvider, executor);
}
```

5. 在业务方法中构建请求。

```java
OutboundRequestInfo<MyResponse> request = builder(MyResponse.class)
        .operation("submit-demo")
        .method(ThirdHttpMethod.POST)
        .url(buildUrl("/api/demo"))
        .body(body)
        .responseType(MyResponse.class)
        .build();

return execute(request);
```

6. 处理特殊响应。

标准 JSON 走默认解析。非标准 JSON、纯文本、文件地址等，用 `OutboundResponseParser`。

7. 处理交换日志。

默认写 slf4j。需要落库、MQ、审计时覆盖 `saveThirdExchangeLog(ThirdExchangeLog log)`。
落库后仍会打印 slf4j；如需关闭打印，覆盖 `printThirdExchangeLog()` 返回 `false`。
不需要记录出站交换日志时，将对应 `ThirdClientOptions.exchangeLogEnabled` 设置为 `false`。

## 注意点

- 配置基类不加 `@Configuration`，项目继承类自己加。
- 不把具体厂商参数沉到公共模块。
- 不在公共模块维护第三方枚举。
- token 缓存、密钥轮换、厂商业务错误码，由业务项目按厂商规则处理。
- HTTP 默认使用 Hutool；确实需要替换时实现 `OutboundExecutor`。
